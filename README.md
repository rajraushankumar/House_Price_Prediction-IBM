# House Price Prediction Using Machine Learning

## AICTE | IBM SkillsBuild Academic Internship – Data Analytics with AI

### Project Overview

This project focuses on predicting house sale prices using Machine Learning techniques.

The project uses the Kaggle House Prices dataset and applies data analysis, data preprocessing, exploratory data analysis, feature engineering, and regression-based Machine Learning models to predict house prices.

---

## Problem Statement

House prices depend on multiple factors such as the overall quality of the house, living area, basement area, garage capacity, and other property characteristics.

The objective of this project is to develop a Machine Learning model that can learn from historical housing data and predict the expected sale price of a house.

---

## Objectives

- Analyze the housing dataset.
- Perform exploratory data analysis.
- Identify important features related to house prices.
- Handle missing values.
- Convert categorical features into numerical representations.
- Train Machine Learning regression models.
- Compare Linear Regression and Random Forest Regression.
- Evaluate model performance using MAE, RMSE, and R².
- Analyze feature importance.
- Save the trained Machine Learning model for future predictions.
